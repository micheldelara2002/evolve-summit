# Frontend / UX Improvement Backlog — 2026-08-14

## P0 — usability blockers

### UX-P0-001 — Global mobile touch-target standard
Create and enforce a single minimum touch target for interactive controls; eliminate recurring per-screen fixes.

### UX-P0-002 — Mobile notification button
Top-right notification control is difficult to hit reliably on mobile. Fix hit area, spacing, positioning and accessible label without relying on the visible icon size alone.

### UX-P0-003 — Edit profile action
Make the profile-edit affordance obvious and reliably tappable on mobile; avoid icon-only micro-controls for a primary account action.

## P1 — consistency and navigation
- UX-P1-004 — Audit all icon-only buttons for touch target and affordance consistency.
- UX-P1-005 — Standardize mobile top bars / page headers.
- UX-P1-006 — Review bottom navigation and section switchers for reachability and state clarity.
- UX-P1-007 — Mobile popovers/dropdowns: avoid cramped or hard-to-dismiss interactions.
- UX-P1-008 — Standardize loading, empty, error and success states.

## P2 — polish/accessibility
- UX-P2-009 — Keyboard/focus/accessibility pass.
- UX-P2-010 — Forms: labels, validation, input sizing and error recovery.
- UX-P2-011 — Admin tables on narrow screens.
- UX-P2-012 — Visual hierarchy, spacing and copy consistency.

## Principle
Fix shared primitives first, then screens. Do not keep patching individual buttons when the underlying interaction contract is inconsistent.
